# Only Up Climb

เกม 3D ปีนขึ้นที่สูงแนว Only Up เล่นในเบราว์เซอร์ได้ทันที เล่นคนเดียวหรือออนไลน์กับเพื่อนได้สูงสุด 4 คน ไม่ต้องติดตั้งอะไร

## เอาขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub แบบ **Public** เช่นชื่อ `onlyup`
2. กด **Add file → Upload files** แล้วลากไฟล์ `index.html` ใส่ จากนั้นกด **Commit changes**
3. ไปที่ **Settings → Pages** ช่อง **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที เกมจะเปิดได้ที่ `https://<ชื่อบัญชี>.github.io/onlyup/`

## เล่นกับเพื่อน
1. คนหนึ่งกด **สร้างห้องใหม่**
2. กด **พัก** แล้วกด **คัดลอกลิงก์** ส่งลิงก์นั้นให้เพื่อน
3. เพื่อนเปิดลิงก์ ใส่ชื่อ แล้วกด **เข้าห้อง**

หัวห้องต้องเปิดเกมค้างไว้ เพราะเครื่องของหัวห้องทำหน้าที่เป็นห้อง ถ้าหัวห้องปิดเกม ห้องจะปิดตาม

## ควบคุม
`W A S D` เดิน · `Space` กระโดด · เมาส์ หมุนกล้อง · ล้อเมาส์ ซูม · `V` สลับมุมมองบุคคลที่ 1/3 · `R` กลับจุดเซฟ · `Esc` พัก
บนมือถือ: ฝั่งซ้ายของจอเป็นจอยเดิน ลากฝั่งขวาเพื่อหมุนกล้อง และมีปุ่มกระโดด

## หมายเหตุ
- ระบบออนไลน์ใช้ WebRTC ผ่าน PeerJS เครื่องผู้เล่นต่อถึงกันโดยตรง จึงไม่ต้องมีเซิร์ฟเวอร์เอง
- เครือข่ายบางแห่งบล็อกการเชื่อมต่อแบบนี้ เช่น Wi-Fi ของบริษัทหรือโรงเรียน ถ้าเข้าห้องไม่ได้ ให้ลองเปลี่ยนไปใช้เน็ตมือถือหรือเน็ตบ้าน
